# mysql的日期时间的数据类型
MySQL的`DATE`、`TIME`、`DATETIME`和`TIMESTAMP`类型

| 类型 | 底层存储格式 | 存储内容 | 时区影响 | 支持范围 |
| :--- | :--- | :--- | :--- | :--- |
| **`DATE`** | 3字节 | 仅日期（年-月-日） | 无 | `1000-01-01` 到 `9999-12-31` |
| **`TIME`** | 3字节+小数秒 | 时间（时:分:秒[.微秒]），可表示时间间隔 | 无 | `-838:59:59` 到 `838:59:59` |
| **`DATETIME`** | 5-8字节 | 日期和时间组合，**静态字面值** | **写入和读取值不变** | `1000-01-01 00:00:00` 到 `9999-12-31 23:59:59` |
| **`TIMESTAMP`** | 4字节+小数秒 | **Unix时间戳**（自1970-01-01 UTC的秒数） | **自动转换为连接会话的时区** | `1970-01-01 00:00:01` UTC 到 `2038-01-19 03:14:07` UTC |
